QrrtqSyncBoard Software Specification

1. Firmware Description

The QrrtqSyncBoard firmware is a specialized measurement system designed for testing semiconductor devices, specifically for reverse recovery charge (Qrr) measurements. The system coordinates multiple hardware modules including DCU (Direct Current Units), RCU (Reverse Current Units), CROVU/FCROVU (Current/Voltage measurement units), CSU (Control and Supply Unit), and SCOPE (high-speed oscilloscope) to perform precise electrical characterization of power semiconductor devices. The firmware manages synchronized pulse generation, real-time data acquisition, and measurement result processing according to GOST standards.

Notes

  • All register addresses are 16-bit values
  • Data types are primarily uint16 (16-bit unsigned integers)
  • Endpoint sizes are configurable based on measurement requirements
  • The system supports both CAN and RS232 communication protocols
  • Calibration parameters are stored in non-volatile memory
  • The firmware implements GOST-compliant measurement procedures
  • Real-time data acquisition operates at 10kHz update rate
  • Safety interlocks are implemented for high-voltage operation
